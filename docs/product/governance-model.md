# Governance model

- Independent product ethics and safety advisory board: labour law, privacy, investigations, workplace psychology, union/employee voice, security and human rights.
- Tenant integrity committee: policy approval, conflict oversight and aggregate metrics; no default case access.
- External ombuds/escalation partner: senior-person and unsafe-route cases under transparent contracts.
- Security and privacy council: threat model, incidents, access reviews, suppliers and assurance.
- AI governance committee: use-case approval, model cards, impact assessments, evaluation and prohibited-use enforcement.

Governance records should be versioned, signed and published in the trust centre where disclosure does not create security risk.
