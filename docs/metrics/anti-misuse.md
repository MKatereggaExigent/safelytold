# Metric Misuse Safeguards (per §18.3)

## Principles
1. Fewer reports ≠ success; low volume may indicate fear.
2. Fast closure ≠ fairness; complex cases need time.
3. High substantiation ≠ better; evidence mix varies.
4. Never rank employees/managers from allegations.
5. Sentiment analysis cannot identify or punish reporters.

## Controls
- Governance review before publishing new KPI dashboards.
- Redact/aggregate metrics to cohort level; minimum thresholds before display.
- Require narrative context for board reports (qualitative + quantitative).
- Advisory board audits metrics quarterly to ensure compliance.
