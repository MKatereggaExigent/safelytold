# Design Partner Offer – Outline

## Purpose
Provide early adopters with a governed pilot: independent escalation, anti-retaliation, measurable trust outcomes.

## Package Components
- HELP ME MVP deployment (journal + intake + mailbox + basic case workspace).
- Dedicated customer success + product lead.
- Legal/privacy workshops (PDA/POPIA mapping).
- Advisory board office hours.
- Pilot metrics + anonymised lessons report.

## Partner Commitments
- Pay reduced pilot fee (Rxxx) + commit resources (triage team, integrity committee).
- Sign anti-retaliation rider + independent escalation agreement.
- Allow anonymised publication of learnings.

## Timeline
- Discovery (4 weeks)
- Configuration + training (4 weeks)
- Live pilot (12 weeks)

## Success Criteria
- ≥X HELP ME submissions or verified test cases.
- Retaliation monitoring active.
- Design-feedback workshops completed.
