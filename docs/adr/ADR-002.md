# ADR-002: Temporal Owns Case Workflow

- **Status:** Proposed
- **Context:** §13.1, ADR list
- **Decision:** Case lifecycle, retaliation follow-ups, and long-running human workflows will be orchestrated with Temporal (cloud or self-hosted). Celery/short-lived queues may handle simple background jobs but will not be authoritative for case state.
- **Consequences:**
  - Durable execution, timers, and retry semantics aligned with month-long investigations.
  - Requires Temporal cluster operations + worker discipline.
  - Developers must express workflows/activities in Python to fit the modular monolith.
- **Next Steps:** Prototype Temporal namespace + sample workflow in Phase 2; document hosting model.
