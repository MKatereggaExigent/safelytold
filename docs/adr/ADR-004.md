# ADR-004: RabbitMQ as Optional Integration Bus

- **Status:** Proposed
- **Context:** §13.2
- **Decision:** RabbitMQ may be deployed to fan out integration events (notifications, HRIS sync, webhooks). It will consume from the transactional outbox; it will not be the source of truth for case state.
- **Consequences:**
  - Enables decoupled integrations without forcing every deployment to run RabbitMQ.
  - Requires idempotent consumers, replay protection, DLQs.
- **Next Steps:** Define event schemas + outbox pattern before enabling RabbitMQ; document optional nature in infra scripts.
