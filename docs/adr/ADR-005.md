# ADR-005: Separate Anonymous Reporter Realm

- **Status:** Proposed
- **Context:** §12.2, trust commitments
- **Decision:** Anonymous reporters authenticate via case code + recovery secret (or passkey), using identity infrastructure entirely separate from corporate SSO / staff auth. Optional identified data resides in a dedicated encrypted vault with purpose binding.
- **Consequences:**
  - Enhances privacy and trust, avoids corporate telemetry leakage.
  - Requires dual auth stacks + consistent policy enforcement across realms.
- **Next Steps:** Define technical boundaries (domains, cookies, storage) and implement vault service with separate keys.
