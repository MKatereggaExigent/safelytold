# ADR-007: Sealed Original Evidence + Working Copy

- **Status:** Proposed
- **Context:** §11.5, §13.2
- **Decision:** Every uploaded file is stored as (a) sealed immutable original (hash, object lock) and (b) sanitised working copies for analysis/redaction. Working copies may be modified; originals remain untouched for audit/legal hold.
- **Consequences:**
  - Supports integrity verification and legal requirements.
  - Requires storage design with object versioning + metadata to link working copies.
- **Next Steps:** Define storage schema, hashing algorithm, manifest format in Phase 2 evidence service design.
