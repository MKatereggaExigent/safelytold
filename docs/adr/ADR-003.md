# ADR-003: Prefect for Derived AI/Data Pipelines

- **Status:** Proposed
- **Context:** §13.3
- **Decision:** Prefect will orchestrate non-authoritative flows such as document sanitisation, translation, redaction, chronology extraction and analytics aggregation, keeping them separate from the Temporal case workflow.
- **Consequences:**
  - Clear separation between core case state and derived/AI tasks.
  - Adds Prefect agent/automation infra but avoids overloading Temporal with heavy data jobs.
- **Next Steps:** Stand up Prefect workspace once evidence pipeline is defined; create guardrails for privacy-safe data access.
