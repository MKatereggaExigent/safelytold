# ADR-010: Multi-Tier Tenancy Options

- **Status:** Proposed
- **Context:** §12.1
- **Decision:** Offer three isolation tiers—shared tenancy, dedicated database, and dedicated stack/VPC. All tiers use per-tenant encryption keys; high-risk customers can choose sovereign hosting and customer-managed keys.
- **Consequences:**
  - Supports affordability while accommodating regulated buyers.
  - Adds deployment complexity (infra automation per tier).
- **Next Steps:** Define control-plane metadata model, provisioning pipeline, and key-management approach in infrastructure docs.
