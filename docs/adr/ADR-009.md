# ADR-009: No Raw Case Content in Events or Logs

- **Status:** Proposed
- **Context:** §13.4, §15.1
- **Decision:** Domain events (e.g., case.reported, evidence.received) and logs will carry identifiers + minimal metadata only. Narratives, attachments, identities, and sensitive fields stay in primary storage; observability tooling receives redacted IDs.
- **Consequences:**
  - Limits blast radius of broker leaks/log aggregation.
  - Requires structured logging guidelines + observability tooling configuration.
- **Next Steps:** Finalise logging standards doc (`docs/security/logging-standards.md`) and enforce via lint/tests.
