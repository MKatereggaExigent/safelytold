# ADR-006: RBAC + ABAC/ReBAC + Conflict Graph

- **Status:** Proposed
- **Context:** §12.3
- **Decision:** Access control combines role-based permissions (triage officer, investigator, ombuds) with attribute-based and relationship-based rules (case assignment, organisational unit, conflict graph, declared relationships, purpose). Authorisation decisions will be centrally evaluated; standing admin access is prohibited.
- **Consequences:**
  - Prevents executives or conflicted parties from browsing sensitive cases.
  - Requires policy service, relationship graph storage, and purpose-binding enforcement.
- **Next Steps:** Model access policies in specification file; choose policy engine implementation (custom, OPA, Cedar, SpiceDB) during Phase 2.
