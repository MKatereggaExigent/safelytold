# Research Workstream Artefacts

This directory holds the qualitative research deliverables required in Phase 1:

- `interviews-employees.md` – anonymised findings from employee/reporters.
- `interviews-handlers.md` – findings from compliance/HR/integrity handlers.
- `interviews-investigators.md` – findings from investigators/ombuds.
- `interviews-legal-privacy.md` – notes from labour/privacy lawyers.
- `interviews-employee-reps.md` – insights from unions/works councils.
- `prototype-testing.md` – usability study for anonymous intake/conflict/mailbox.

Each file uses a common template: participants, methodology, key insights, quotes, risks/opportunities, follow-up actions. Update after every research cycle.
