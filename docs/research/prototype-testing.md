# Prototype Testing – Anonymous Intake & Mailbox

**Goals:** Validate comprehension, trust, conflict challenge, mailbox UX across languages/disabilities.

| Item | Details |
| --- | --- |
| Prototype scope | HELP ME landing, multi-mode selection, questionnaire, anonymity assistant, conflict challenge, mailbox flow |
| Participants | Diverse mix by language/literacy/device (min 12) |
| Methods | Remote moderated + unmoderated tests, screen recording optional |

## Test Plan
- Tasks
- Success criteria (time-on-task, comprehension, trust rating)
- Metrics captured

## Findings
- Strengths
- Issues ranked (severity, frequency)
- Recommended changes

## Accessibility Review
- Keyboard-only
- Screen reader compatibility
- Low bandwidth behaviour
