# Privacy Red-Team Exercise – Anonymous Intake

**Objective:** Attempt to deanonymise a synthetic reporter via logs, metadata, attachments, support tickets, admin UI, or analytics, and verify mitigations.

## Scope
- Anonymous landing, report submission, mailbox responses
- Logging systems, APM, security tooling
- Support workflows (Zendesk or equivalent)

## Methodology
1. Define attack hypotheses (IP correlation, unique browser fingerprint, metadata leakage, uploaded file metadata, support backchannel).
2. Execute tests using synthetic data only; document exact steps.
3. Record whether current controls prevented deanonymisation.
4. Recommend mitigations (mask IP, strip metadata, change logging levels, etc.).
